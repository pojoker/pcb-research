# 02 信源分层（PCB）· v1（红队返修版）

> 实例化第 2 步。层级定义沿用总表：T1=强制登记点/发布主体原文｜T2=独立采编｜T3=聚合/转载/自媒体循环层｜🔒=付费墙（登记不采）。
> v1 返修（codex 阻断1/2 + cursor B1/B4）："四腿登记"废除，改为多源登记/观测结构；
> 每个来源钉死 source_role 与可承重事实；8534 降为公司级闸的非默认锚；UL/工信名单/CPCA 降为发现与交叉层。

## 两句硬区分（先钉死）

1. **报告解剖结论保留**：refs/信源分层总表.md §四说的是"招商报告承重 T1 可达率 0%"——那是报告的用锚习惯，不是行业判决。
2. **行业登记结构**：PCB 是"主体披露 + 贸易统计 + 行政许可 + 协会统计 + 自愿认证 + 企业注册"的**多源登记/观测结构**；
   不同来源只对特定事实承重；"存在记录"禁止自动升级为"产能、供货或份额"。供需份额链仍封顶于 🔒 橱窗。

## 来源角色与可承重事实（source_role × 可承重事实）

| 来源 | source_role | 可承重事实 | 禁止承重 |
|---|---|---|---|
| 巨潮/沪深北交易所公告（年报产销量表/分产品表/前五大匿名表/问询回复） | 主体披露（强） | 主体产量/收入/产能规划自述/客户关系槽位 | 行业份额 |
| 公开资讯观测站（台股月营收/年报/法说会） | 主体披露（强，月度脉冲） | 发行人月度合并营收（不拆品类） | 分品类状态/客户信号 |
| SEC（10-K/20-F） | 主体披露（海外观察层） | 海外大厂实名客户考古 | — |
| 海关总署 8534 | 贸易统计（弱/宏观） | 宏观出口流（口径冻结后，见下节） | 公司级发布闸默认锚、内销、面积产量 |
| 环评批复/排污许可公开端 | 行政许可（厂/扩产事件强、数量弱） | 扩产事件真实性、批复产能**弱上界**（人工摘录已核才可用） | 实际产能、机读天顶 |
| 国家企业信用信息公示系统 | 企业注册 | 主体/法人存在性、注册资本、股东 | 产能与经营状态 |
| 工信部《印制电路板行业规范条件》名单 | 行政许可（名单型） | 主体存在与规范底线 | 覆盖完整性（非全量登记簿） |
| UL Product iQ | 自愿认证 | 厂存在性线索、材料体系认证线索 | 准入强制、量产供货、产能 |
| CPCA/TPCA | 协会统计（交叉弱） | 分母交叉、行业轮廓 | 数量承重（CPCA 部分源自 Prismark，回声风险） |

## 8534 物质流口径冻结表（单开 ADR 前不得启用）

冻结项：税则年度与版本 / 完整子目 / 进出口方向 / 数量单位 / 产品范围（刚性/FPC/HDI/载板归类） /
贸易方式白名单（一般贸易/加工贸易/保税物流） / 报关主体口径（生产商/贸易商/EMS/保税厂） /
原产地 / 公司归属方法 / 期间 / 覆盖缺口 / 面积换算锚（**默认禁止**：禁止用橱窗单价循环换算）。
未冻结前：8534 一律标"待核-口径未冻结"，仅作宏观背景，不进任何闸。

## 🔒 橱窗机构（见即标记"不可独立验证"）

**Prismark（垄断级）**、N.T.Information、TrendForce、CINNO、工研院 IEK。
规则：橱窗数字一律进 macro_evidence 带 C 级注记，不承重点/边/推断行输入；
"Prismark → 券商研报 → 自媒体"三层转载 = **1 个来源**（回声室）。
来源独立性元数据（来源登记器规格的输入）：origin_source_id / carrier_url / independence_group / paywall / coverage_scope；
每锚标记 direct / secondary / derived / unavailable。

## 无登记的部分

- 客户-供应商关系层（与光模块同构）——靠匿名前五大表 + 对手方反照 + 披露史考古 + 金额指纹。
- 供需份额总量——封顶于橱窗机构，只进 macro_evidence。
