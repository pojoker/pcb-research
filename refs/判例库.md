# 判例库模板（PCB）· v1（红队返修版）· 空库开工

> 只搬模板与工序阶梯；光模块判例本身不迁移（旧行业证据不作新行业结论）。
> 首例按本模板积累；每判例附陷阱排除与可推翻条件。
> v1 返修：陷阱排除扩至十三项勾选（红队 S3 + codex 建议）。

## 判定等级

- **A** = 多源硬证据互锁，实务当实名用
- **B** = 单一硬证据 + 一致性验证
- **C** = 推断，需显式标注且**不得承重**（推断永不进 A/B）
- **D** = 不足以判定

## 工序阶梯（按序升级，够用即停）

披露史考古 → 程序段落（年报关联交易/重大合同章节） → 中标/定点公告 → 金额指纹。

## 判例模板

```
## 判例#NNN <一句话结论> 【等级】

**槽位**：edges.csv / points.csv 关联行。

**工序路径**：<升到哪一级，未动用哪一级>。

**证据链**：
1. <每条证据带类型化锚 + 检索日期>。
2. <替代解释及排除理由（红队视角）>。

**陷阱排除**：
- [ ] 直接/终端客户口径：<计费对手方≠终端使用方；EMS/ODM 夹层>
- [ ] 会计期：<同口径同期>
- [ ] 汇率：<折算口径与锚>
- [ ] 多实体：<同名/集团主体混淆排除>
- [ ] 贸易商夹层：<夹层实体是否即答案>
- [ ] 集团/主体口径：<母集团合并≠分拆主体；母子各自上市不得重复计入>
- [ ] 保税/加工贸易：<保税区出境≠境内总出货；来料≠进料≠OEM/ODM/EMS>
- [ ] 外发工序归属：<capacity_owner / process_operator 分开；外协产出≠自有产能>
- [ ] 载板混格：<FAB1/FAB2 是否分列>
- [ ] 锂电铜箔：<电子电路用途判定>
- [ ] 面积单位/期间：<平方米≠片数；大板片数≠成品片数；期间对齐>
- [ ] TPCA 口径：<台商两岸产值≠大陆主体产销表；禁止无规则双计>
- [ ] 厂址/法人/发行人：<plant≠legal_entity≠issuer>

**判定**：<结论 + 等级 + 互锁要点>。

**剩余不可知（诚实边界）**：<公开信息不可判定部分，标 D 级>。

**可推翻条件**：<若出现何种新证据则降级/推翻>。
```

## 铁律

- 身份指纹成立 ≠ 物流穿透成立：判例只解"计费/披露对手方是谁"，不证明货物实际流向。
- 匿名窗口会关闭：先存档再分析，考古趁早。
- C 级不承重：推断行/判例 C 级不得作为点/边/推断输入。
