## 研究范围声明（2026-08-28 已批准 G1-A）

**核心物理分母 = 中国大陆生产能力**；A 股板厂、A 股材料商、A 股设备/耗材商分别为 L1-A/B/C；
台股发行人完整清单为 L2 筛选母集，港股为 L3，未上市主体为 L4；海外只进观察名单，不进入核心定量分母。
L2/L3 的发行人披露可作为披露分母，但其全球收入、台湾或其他境外厂址不得自动计作中国大陆生产能力。

## 四类 ID（分母行与输出记录的字段映射）

- `issuer_id`：上市发行人（如 002463、4958.TW）
- `legal_entity_id`：法人主体（如珠海越亚科技）
- `plant_id`：生产厂址（环评/排污/UL 落在这类）
- `group_id`：集团（建滔集团、臻鼎-KY 等合并口径）

厂址 ≠ 法人 ≠ 发行人；集团与成员单位口径分列，禁止混写。每条记录必须声明其主身份
`reporting_subject_id` 与 `reporting_subject_type∈{issuer, legal_entity, plant, group}`，并保留可得的其余三类 ID；
缺失 ID 必须显式说明未知原因，不得从名称猜配。

## 原则

1. **分母按格分层，不是行业股票池**——板厂、材料商、设备商各有各的分母层（结构先于公司）。
2. **机械口径优先**——能用交易所/协会分类机械圈定的，不手工挑选（防幸存者偏差）。
3. **分母与挂格分离**——先冻结完整主体表（分母动作），再凭分部/产品证据挂 M/PM/EQ/FAB 格（挂格动作）；两动作不得混为一张股票池。
4. **分层冻结**——每层独立冻结日期与来源；增列/移出走 inclusion_decision.csv 留痕。
5. **未上市 ≠ 未解析**——未上市私企入 L4 层，与上市层同权扫描。
6. **地理范围显式化**——每项物理比较须声明 `production_geography`；发行人/集团披露另声明
   `reporting_scope`，两者不因主体关联而自动互换。

## 手工增列纪律（L1-B/C、L3 必走）

手工增列入 `inclusion_decision.csv`：主体 ID / 厂址 / 纳入理由 / 排除理由 / 证据锚 / 裁决人 / 裁决日期。
禁"申万相关成分 + 手工"混写——"相关"没有定义就是研究员主观选股（codex 重要9）。

## 双计契约（2026-08-28 已批准 G2-A）

### 先分输出，再允许比较

物理输出与披露输出是两张独立账；不得默认 join 后相加，也不得以披露收入替代物理产量。
任何桥接表必须说明桥接目的，并保持两边原始口径可回溯。

**物理输出记录**用于厂址/产线层的实物或产能观测，最小去重键为：
`plant_id + line_or_asset_id + finished_board_cell + product_family + metric_type + unit + period_start + period_end + period_type + metric_definition + physical_flow_id`。
`legal_entity_id`、`issuer_id`、`group_id` 是该记录的身份映射而非物理加总键；同址多法人不得仅按厂址粗暴合并，
必须用 `line_or_asset_id` 或明确的同一 `physical_flow_id` 判断是否同一物理流。

**披露输出记录**用于主体披露原貌，最小去重键为：
`reporting_subject_id + reporting_subject_type + reporting_scope + consolidation_basis + finished_board_cell + product_family + metric_type + unit_or_currency + period_start + period_end + period_type`。
金额指标必须填 `currency`，非金额指标必须填 `unit`；`consolidation_basis` 必须显式区分单体、合并及集团口径，
不得由发行人名称推断。

`metric_type` 至少区分实际产量、销量、收入、批复产能、建成产能；不同 `metric_type` 不得互替。
`period_start`、`period_end`、`period_type` 是比较前提，缺一不得比较。

### 成品、价值链与主体对

- 裸板产量聚合只接受 `stage=finished_board` 且 `finished_board_cell∈{FAB1,FAB2}` 的物理记录；FAB1 与 FAB2 永远分列。
- 材料 `flow_id/stage` 仅用于材料流纪律；CCL 含箔与独立 M3 商品箔、以及其他价值链上下游，不得默认相加。
- 母子各自上市（臻鼎-KY×鹏鼎控股、建滔集团×建滔积层板、生益科技×生益电子）保留各自披露行；
  禁止加总的主体对必须进入可扩展、版本化的 `prohibited_additive_subject_pairs` 注册表，并带关系证据、适用期间与裁决留痕。
- 集团合并与分拆主体的披露都可保留；合并口径只作交叉校验，不能与成员主体相加。

### 委外/外发

任何委外、受托、表面处理外协、来料加工或返工再处理边，必须同时填写
`capacity_owner`、`process_operator`、`contracting_party`、`product_integrator`、`seller_of_record`，
以及边类型、关系期间和证据锚。产能归属必须按 `capacity_owner` 与 `process_operator` 分列；
外协产出不得默认归给披露主体或与委托方自有产能相加。

## 红线

- 分母未定案前不扫描、不画树、不入点。
- 增列/移出分母必须判定闸留痕（inclusion_decision.csv）。
- 铜箔厂入 L1-B 前必须过"锂电/电子电路"用途判定；锂电为主者入观察名单，不进 M3 格分母。
- 混合主体（板+贴装、板+覆铜板、集团母子）逐条记录必须填写 `business_scope`、`metric_scope`、`split_evidence_id`；
  无法以证据拆开裸板、载板、贴装与其他业务时，保留覆盖分母但阻断该量化记录进入 FAB 统计（不变量⑱）。
- 种子示例全部"待核"，禁止示例被当已冻结宇宙。
