## 研究范围声明（待用户裁决；默认提案）

默认提案：**核心宇宙 = 中国大陆生产能力 + 台/港发行人层 + 海外观察名单**；不做全球全量。
（范围决定分母单位与 T1 清单，开工前必须由用户裁决确认。）

## 四类 ID（分母行必须声明落在哪类）

- `issuer`（上市发行人，如 002463、4958.TW）
- `legal_entity`（法人主体，如珠海越亚科技）
- `plant`（生产厂址，环评/排污/UL 落在这类）
- `group`（集团，建滔集团、臻鼎-KY 等合并口径）

厂址 ≠ 法人 ≠ 发行人；集团与成员单位口径分列，禁止混写。

## 原则

1. **分母按格分层，不是行业股票池**——板厂、材料商、设备商各有各的分母层（结构先于公司）。
2. **机械口径优先**——能用交易所/协会分类机械圈定的，不手工挑选（防幸存者偏差）。
3. **分母与挂格分离**——先冻结完整主体表（分母动作），再凭分部/产品证据挂 M/PM/EQ/FAB 格（挂格动作）；两动作不得混为一张股票池。
4. **分层冻结**——每层独立冻结日期与来源；增列/移出走 inclusion_decision.csv 留痕。
5. **未上市 ≠ 未解析**——未上市私企入 L4 层，与上市层同权扫描。

## 手工增列纪律（L1-B/C、L3 必走）

手工增列入 `inclusion_decision.csv`：主体 ID / 厂址 / 纳入理由 / 排除理由 / 证据锚 / 裁决人 / 裁决日期。
禁"申万相关成分 + 手工"混写——"相关"没有定义就是研究员主观选股（codex 重要9）。

## 去重规则（双计键）

- 母子各自上市（臻鼎-KY×鹏鼎控股、建滔集团×建滔积层板、生益科技×生益电子）：两行均留，统计输出强制分列，禁止加总（不变量⑰）。
- 同一工厂多法人：以 plant ID 去重，披露口径各记各行。
- 集团合并 vs 分拆主体：挂载与统计以披露主体为准，合并口径只作交叉校验。
