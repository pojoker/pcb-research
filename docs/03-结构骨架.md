## 总体：双体系 + 需求侧

PCB 与光模块同为制造出来的物理件，直接继承双体系：

- **物理知识体系**＝裸板的构成材料 + 制造工序 + 设备耗材（"在板上/在工序里"）+ **成品制造格 FAB（"造板的"）**。
- **技术路线体系**＝板型 × 层数 × 线宽 × 材料损耗 × 孔结构 × 特殊工艺 的正交轴组合。
- **需求侧**＝下游场景坐标（不作 cell，作路线需求）。

## 成品轴（裸板制造，主宇宙挂载格）

| 格 | 名称 | 边界句 |
|---|---|---|
| FAB1 | 普通裸板制造 | 刚性多层/HDI/FPC/刚挠/金属基/高频/背板的裸板制造；品类用刻面表达，不开新格 |
| FAB2 | IC 载板制造 | BT/ABF 封装基板制造；**禁止与 FAB1 混格加总**（材料/制程/资本强度/客户结构不同） |

- 工序外协专营厂（沉金/钻孔/电测等外发承接方）：**不开 FAB 格**，挂对应 P\* 格 + 角色`工序外协`；
  外协角色**禁止填自有产量推断**（机检，不变量⑳）。
- `product_family`（产品族）为挂载/产量/收入/海关数据的**一级必填字段**：
  普通刚性 / HDI / FPC / 刚挠 / IC 载板 / 金属基 / 高频 / 背板。
- **树外不是第三个成品格**：`OUT` 只表示树外命名空间，绝不是 `cell_id`。PCBA、SMT、EMS、设计、整机、锂电铜箔是
  `outside_neighbors`；它们不得挂 FAB 格或与 finished-board 输出加总。
- **混合主体按记录隔离**：板、载板、贴装和其他业务共存的主体，必须有 `business_scope`、`metric_scope` 与
  `split_evidence_id` 才可把相应记录挂入 FAB；拆不开时保留主体覆盖，但阻断量化记录。

## 材料轴（构成材料，留在板上）

每格带 `stage`（基础原料/板厂投入件/板面层）与 `flow_id`；**同一 flow_id 不得跨 stage 重复进入同一统计分母**；
跨格加总必须先声明可加总关系（价值链同流禁止双计）。材料流与 finished-board 输出是不同输出，不得默认混加。

| 格 | 名称 | stage | 边界句（判定键写死） |
|---|---|---|---|
| M1 | 覆铜板 CCL | 板厂投入件 | 树脂+玻纤+铜箔复合成品（刚性），板厂单一采购件；**含箔价值不得再计一次 M3 商品供给** |
| M2 | 半固化片 PP | 板厂投入件 | B 阶粘结片；不含已复合进 CCL 的部分 |
| M3 | 电子电路铜箔 | 基础原料 | 作为**独立商品**流通的铜箔（HVLP/RTF/载体/压延/电解）；判定键：**对外商品箔才挂 M3，自产箔进 CCL 只挂 M1**；锂电铜箔不进本格 |
| M4 | 基体树脂与固化体系 | 基础原料 | **合法活动 `cell_id`**；**未复合**树脂（环氧/聚苯醚/碳氢/PTFE/PI/BT/ABF 用树脂）。判定键：已复合进基板商品 → M1/M9/FLX，不再挂 M4；仅裸词表词形禁入，不影响 `cell_id=M4` |
| M5 | 增强与填料 | 基础原料 | 电子玻纤布/毡/纱；硅微粉/球形硅/氧化铝 |
| MSK | 阻焊与文字油墨 | 板面层 | 留在板面的永久油墨层（原 M6 改名：M6/M8 为损耗等级俗称保留字，见 04-词表） |
| M7 | 表面处理材料 | 板面层 | 判定键：**成为最终可焊表面镀层体系**（金盐/镍盐/沉银/沉锡/OSP/电镀光剂）→ M7；否则湿制程 → PM2 |
| FLX | FPC 专用材料 | 板厂投入件 | 判定键：**已成卷材 FCCL 商品且仅柔板用** → FLX；刚性 CCL → M1；含 PI 基膜/覆盖膜/纯胶/补强板/电磁屏蔽膜（原 M8 改名） |
| M9 | 载板专用材料 | 板厂投入件 | 判定键：**载板用 ABF 膜/BT 基板/薄铜箔/核心板商品** → M9；未复合树脂 → M4 |

## 技术路线体系（路线选择轴）

- 轴A 板型：刚性多层 / HDI（1-N 阶/Anylayer） / FPC / 刚挠结合 / IC 载板（BT/ABF） / 金属基板 / 高频板 / 背板
  （轴值是路线坐标，**不得直接开成物理格**——市场分类不算数）
- 轴B 层数：单双 / 4-8 / 10-16 / 18-24 / 26+
- 轴C 线宽线距：≥75μm / 50-75 / 30-50 / <30（mSAP/SAP）
- 轴D 材料损耗：常规 FR-4 / 中损耗 / 低损耗 / 超低损耗 / PTFE·碳氢射频级
  （损耗等级市场裸词 M4/M6/M8 均为**保留词形**，禁止作为正式等级名或词表词形；`M4` 同时是合法活动树脂
  `cell_id`，仅可在 `cell_id` 命名空间使用；M6/M8 不是活动 target。表达用"低损耗/超低损耗 + 料号"。）
- 轴E 孔结构：通孔 / 盲埋孔 / 任意层互连 / 背钻 / 树脂塞孔 / 盘中孔 VIPPO
- 轴F 特殊工艺：厚铜（≥3oz） / 埋嵌铜块 / 高频混压 / 大尺寸厚背板 / 散热结构

## 挂载规则

1. 公司实体唯一，按证据多格挂载，**挂载一律写 cell_id**（禁裸写"板厂"）；角色由引语动作支持
   （材料供应/铜箔供应/药水供应/设备供应/工序外协/裸板制造/载板制造）。
2. 挂载以披露主体为准；集团母子分列（建滔集团/建滔积层板、生益科技/生益电子、臻鼎-KY/鹏鼎控股）；
   **母子各自上市收入/产量禁止重复计入**（不变量⑰）。
3. 空格是合法状态（"有证据的空"）；空格必须带检索记录（关键词/范围/日期/命中数）。
4. **制造关系模型**（委外/外发必填）：`capacity_owner`（产能所有者）/ `process_operator`（工序运营者）/
   `contracting_party`（签约委托方）/ `product_integrator`（成品集成方）/ `seller_of_record`（销售确认方）；
   边类型增：委外加工 / 受托加工 / 表面处理外协 / 来料加工 / 返工再处理；每条边还必须带关系期间与证据锚。
   产能统计按 process_operator 或 capacity_owner 分开，**不允许默认归给披露主体**。
5. 候选挂载示例（**待判定闸，不是结论**）：生益科技→M1/M2；宏和科技→M5；东材科技/圣泉集团→M4；
   方邦股份→FLX；光华科技→PM2/M7；广信材料/容大感光→MSK/PM1；大族数控→EQ2/EQ1/EQ6；东威科技→EQ3；
   芯碁微装→EQ1；鼎泰高科/金洲精工→PM3；沪电股份/胜宏科技/生益电子→FAB1（高速高多层刻面）；
   景旺电子→FAB1（刚性+柔性+金属基刻面）；崇达技术→FAB1（小批量角色）；兴森科技→FAB1（样板角色）+FAB2；
   鹏鼎控股/东山精密/弘信电子→FAB1（FPC 刻面）；深南电路→FAB1+FAB2；珠海越亚→FAB2（L4 未上市）。
6. 驳回预演：嘉元科技/诺德股份命中"铜箔"→锂电为主，**驳回-非本格**（M3 仅电子电路用途），留痕进判例库。

## 开格四标准（PCB 版，判定闸引用）

四条全过才开新格：

1. **BOM/工序真实性**——必须是裸板的物理构成、制造裸板的必经工序/设备/耗材，或裸板制造本身（FAB）。
   检验：能指出它在板上/工序里/制造链上的物理位置。市场分类不算数。
2. **不可归约**——现有格扩界后仍装不下，才开新格。
3. **证据可得**——宇宙内至少一家有披露级证据；或"有证据的空"（带检索记录）。
4. **边界可写**——一句话写得清什么进、什么不进，未来候选可机械判定。

判定顺序：在板上吗 → 在工序里吗 → 造板的吗 → 现有格装得下吗 → 有证据吗 → 边界写得清吗。
卡 1/2/3 → 树外（PCBA/锂电铜箔/整机）；卡 4 → 扩界；卡 5 → 待判挂监视；卡 6 → 先搞懂环节。
开格即流向：新格必须同时声明 flows；开新格先查格 ID 保留字（不变量⑲）。
空格合法，不为了消灭空格而开格。
