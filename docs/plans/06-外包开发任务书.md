# 06 外包开发任务书（PCB 实例化）· v1（人闸裁决已同步）

> 制宪 v1 冻结后的开发包拆分。规格来源：05-不变量清单 + 本地 Kimi Code/Cursor Agent 双审后的用户裁决。
> 总原则：**人闸不可外包，机械实现可外包**；验收不认"测试通过"字样，必须过反例 fixtures。

## 总边界：人闸 vs 可外包

**不可外包（判定闸/用户裁决）**：分母层定义与双计键、混合主体拆分规则、开格四标准判定、
T1 承重资格、8534 适用域 ADR、歧义词收/弃、判例等级与可推翻条件、FAB/OUT 边界句终审、研究范围裁决。

**已裁决、可机械落实的契约（2026-08-28）**：G1-A/G2-A/G3-A/G4-A/G5-A/G6-A。开发方必须实现其
阻断条件，不得改写裁决；容差 ADR 与汇率 ADR 仍为 `pending`，不得自行设定默认值或折算规则。

**可外包（机械实现）**：成分抓取、快照、schema 落地、校验器、正则编译闸、碰撞统计、diff 报告、回声检测。

## 波次（工具后置纪律）

- **波 1（立即，服务实例化 1/2/4 步）**：DP1 分母登记器、DP2 来源登记器、DP4 词表实测器。
  波 1 只做"探测与草稿"，不写死结论；宪法 v1 冻结前产出全部标"待核"。
- **波 2（人闸契约已冻结，服务 3/5 步与集成）**：DP3 树结构校验器、
  DP5 证据/委外账本校验器、DP6 发布闸、DP7 判例库校验器。

## 开发包

### DP1 分母登记器（波 1）

- 交付：交易所/协会成分抓取 + 快照（URL+查询日）+ `_frozen.csv` schema + 增删 diff 报告。
- 输入：01-宇宙分母.md（层定义 / 四类 ID 映射 / 纳入排除规则 / 双计契约）。
- 验收：每层四字段齐（代码/名称/层级/登记源+查询日）；L2 完整发行人清单作为筛选母集而非大陆物理产能自动分母；
  母子双计测试用例（臻鼎-KY×鹏鼎、建滔集团×积层板、生益科技×生益电子）；增删必出 triage 行；
  inclusion_decision.csv schema 落地。

### DP2 来源登记器（波 1）

- 交付：来源台账 schema（origin_source_id / carrier_url / independence_group / paywall /
  coverage_scope / direct|secondary|derived|unavailable）+ T1 可达性探测脚本 +
  8534 口径冻结表模板 + Prismark 回声检测（同一数字跨域名聚类）。
- 验收：T1 清单逐条探测记录（可达/不可达+日期）；回声检测对一篇已知研报复现"三层转载=1 来源"；
  8534 冻结表缺任一项（税则年度、完整子目、方向、数量单位、产品范围、贸易方式、报关主体、原产地、
  公司或地区归属方法、期间、覆盖缺口、换算锚）即标"待核-口径未冻结"；8534 只限宏观校准。

### DP4 词表实测器（波 1）

- 交付：结构化词表 schema（term / match_mode / include_patterns / exclude_patterns / target_cell /
  case_policy / test_fixture_ids）+ 正则编译闸 + 语料实测四键记录器 + 碰撞统计报告。
- 验收：无裸缩写入表；golden fixtures（正例/反例/边界例）全过；SAP/HDI/BT/PCB 负样本集全灭；
  正则不可编译直接阻断；格 ID 保留字冲突检（不变量⑲）。

### DP3 树结构校验器（波 2）

- 交付：tree.yaml schema 校验 + 空格渲染 + flows 声明检 + cell 保留字检 +
  process_equipment_map 多对多映射检。
- 验收：板厂样本 100% 挂 cell_id（禁裸写"板厂"）；`cell_id=M4` 通过、裸词 M4 与 M6/M8 拒绝、M6/M8 非活动 target 的 selftest；
  OUT 不是 cell 且 outside_neighbors 不得挂 FAB；
  未映射工序-设备对不得兜底 EQ6/EQ7。

### DP5 证据/委外账本校验器（波 2）

- 交付：points/edges schema 扩展（四类 ID 映射；制造关系五元组 capacity_owner / process_operator /
  contracting_party / product_integrator / seller_of_record；外发边类型、关系期间、证据锚）+ 互斥校验；
  物理输出与披露输出的独立键及禁止加总主体对注册表。
- 验收：外协角色填自有产量推断 → 红（⑳）；产品族缺失 → 红（⑯）；母子双计或未登记的禁止加总主体对相加 → 红（⑰）；
  PCBA/EMS/设计收入挂 FAB 或混合主体缺 business_scope/metric_scope/split_evidence_id → 红（⑱）；
  裸板物理产量非 finished_board/FAB → 红。

### DP6 发布闸（波 2）

- 交付：三态状态机（pass / fail / indeterminate）+ 8534 仅宏观适用域检查 +
  产能天顶（人工摘录已核）+ 校准列回算；只有 pass 才允许正式发布。
- 验收：口径不可比输出 indeterminate（禁静默通过）；缺锚 → 红；NaN/Inf → 红；
  8534 元数据缺一 → indeterminate（㉑）；公司/厂址级 8534 校准 → 红；期间/主体/单位或币种/合并口径不齐 → 不得比较（㉒）；
  fail 与 indeterminate 均不得进入正式发布。容差 ADR 与汇率 ADR 未批准时，必须保持 pending。

### DP7 判例库校验器（波 2）

- 交付：模板字段校验 + 十三项陷阱勾选完备性 + 锚类型机检。**不自动生成行业结论**。
- 验收：空库可开工；陷阱勾选缺失 → 红；C 级被引用承重 → 红。

## 反例 fixtures 总表（每包验收必备）

## 建议发包方式

- 每个 DP 一个工作项：write_scope 冻结到包内文件，read_only_dependencies 显式列出；
  交付=代码+selftest+fixtures 报告；验收由独立 reviewer（非开发方）执行。
- 沿用光模块项目（workflow-rehearsal）refs/CODEX-KIMI-COLLAB.md 的工作项协议格式（认领/回执/交付状态分离）；
  本项目开工后建立自己的协作账本；canonical 账本文件对开发包永远只读。
