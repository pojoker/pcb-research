# PCB 项目开工前科（第一天就要防）· v1（红队返修版）

> 来源：光模块项目实战事故 + 迁移预演 + codex/cursor 红队评审（2026-08-26）。每条：坑 → PCB 形态 → 防线。

## 通用前科（行业无关，原样继承）

1. **横表错位**——PDF/表格抽取行列错位，光模块项目四次拦截，最严重一次单位差 1000 倍。
   PCB 形态：年报"主要产品产销量表"（平方米）与"分行业/分产品收入表"（万元）同页并排；台股年报与月营收口径混排。
   防线：承重数字逐列回原文表区对位；二手数字 100% 回一手原文。
2. **回声室冒充多源互证**——十篇转载同一源头 ≠ 十个独立来源。
   PCB 形态：Prismark 数字 → 券商研报 → 集微/PCB007/电子发烧友三层转载。
   防线：来源独立性按信息源头算（origin_source_id/independence_group），不按文章数算。
3. **校验通过 ≠ 语义合法**——往枚举里加哨兵值让校验通过是最危险的操作；"用户批准入库"不等于新数据继承旧表语义。
4. **关键词子串炸弹**——裸缩写必撞车。每词必须登记可编译排除正则，入表前实测语料。
   PCB 撞车预演（详见 04-词表）：PCB=多氯联苯、SAP=软件公司、HDI=异氰酸酯、PP=聚丙烯、BT=下载/蓝牙、MLB=棒球、M8=宝马/格ID、VCP=VMware、AOI=GIS 兴趣点、OSP=开放服务平台、RTF=富文本、PPO=美国医保、MPI=并行接口、EMC=电磁兼容、黑化=网文用语。
5. **扫描零命中 ≠ 不参与**——发现机制与准入机制必须解耦，否则披露语言不规范的知名公司会隐形。
6. **例外/豁免不留痕**——系统不会死于纪律太松，会死于自己合法开的口子。例外必须成文（ADR/判例），禁止在代码里加 if。
7. **数据抓取三铁律**——合并语义只增不减；新数据源两家对比冒烟测试；零结果双通道验证。
8. **结构树一定会画错**——开格/扩界/树外写成判定标准+判例（03-结构骨架附四标准），不临时拍脑袋。
9. **实名披露窗口会关闭**——客户/供应商实名表可能下一年匿名化；先存档再分析，考古趁早。
   PCB 形态：台股/美股大客户实名表、招股书客户供应商章、问询回复、年报前五大表。
10. **工具后置**——摩擦≥3 次才立项建工具，先跑流程攒摩擦记录。

## PCB 新增前科（预演 + 红队确认）

11. **锂电铜箔冒充 PCB 铜箔**——动力电池箔占大头的铜箔厂，其产能叙事 ≠ 电子电路铜箔供给。
    防线：铜箔格边界句写明"仅电子电路用途"；命中锂电语境按"驳回-非本格"留痕。
12. **PCBA 冒充 PCB**——设计+贴装+小批量板混合主体的收入口径必须拆开；贴装是树的下游邻居，默认树外；无拆分规则 → 阻断（不变量⑱）。
13. **集团合并口径冒充主体**——建滔集团 ≠ 建滔积层板；生益科技合并 ≠ 生益电子；臻鼎-KY ≠ 鹏鼎控股。
    母子各自上市时收入不得重复计入；挂载以披露主体为准。
14. **环评/公告产能冒充实际产能**——批复产能、建成产能、实际产量三态分列；规划口径 ≠ 状态变化；
    批复产能只作弱上界，禁止当默认可机读天顶（环评分散在省级系统、PDF/扫描件、分期建设、单位混杂）。
15. **载板与普通板混格**——IC 载板（BT/ABF）材料、制程、资本强度、客户结构与普通板不同；制造落 FAB2，禁止混格加总（不变量⑯）。
16. **台股月营收过度解读**——月营收不拆品类/客户；单月同比波动不得推断单品类/单客户状态变化。
17. **8534 单位陷阱**——海关序列是金额/重量，账本是平方米；无成文换算矩阵时禁止比较；
    禁止用橱窗单价循环换算面积；出口流 ≠ 中国产量上限（内销/保税/加工贸易错位）。
18. **TPCA/大陆双计**——同一物理产线的"台商两岸产值"与大陆主体披露禁止无规则双计。
19. **格 ID 命名空间污染**——格 ID 是保留字（M6/M8 案：阻焊格与损耗俗称撞车，红队 B3）；
    开新格先查保留字表；俗称禁止作格 ID 与裸词。
20. **委外产能归属错误**——外发钻孔/电镀/表面处理的产出 ≠ 委托方自有工序产能，双方产能禁止加总；
    制造关系五元组必填（不变量⑳）。
21. **裸缩写 SAP**——软件公司 vs 半加成制程；只收 mSAP/SAP制程/半加成。
