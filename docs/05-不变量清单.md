# 05 不变量清单（PCB 版蓝本）· v1（红队返修版）

> 对应光模块 scan.py --check 的 ①-⑭，PCB 适配并新增 ⑮-㉒。
> 纪律：不变量写成可执行校验器，校验器自身带 selftest；纪律不靠自觉。
> 工具后置：本清单先以人工逐项核，摩擦攒够后落 scan.py。
> v1 返修（codex 阻断5/14、建议15/16/17 + cursor I10/I11）：⑮ 改三态状态机；新增 ⑯-㉒；
> 明示 PCB scan.py 重写时不自动继承光模块现行字段。

| # | 名称 | 防什么 | 校验逻辑要点 |
|---|---|---|---|
| ① | 分母闭合 | 语料目录无分母行 | 分母分层（L1/L2/L3/L4），每层独立 _frozen；台股层为完整发行人筛选母集；分母行带四类 ID（issuer_id/legal_entity_id/plant_id/group_id）与主身份映射；发行人分母不得自动等同中国大陆物理分母 |
| ② | 端点闭合 | edge 端点悬空 | 原样 |
| ③ | 自指零豁免 | 生产点不在分母 | 扩展：台股点须在 L2 分母；宇宙外观察须在 tree 观察名单 |
| ④ | 单位量级 | 金额/面积单位错（千倍事故） | 面积量级检（平方米，期间系数）；币种枚举加 TWD/HKD/JPY/KRW（汇率折算口径须 ADR 成文，禁止硬编码继承旧值） |
| ⑤ | 枚举合法 | 哨兵值混过校验 | 上市标签候选增"韩股"；任何枚举变更须 ADR |
| ⑥ | 白名单 | 根文件/越位 md 失控 | 原样（refs≤8） |
| ⑦ | triage 一致性 | 已入点但 points 无此公司 | 原样；驳回理由枚举随 PCB 判例成文增补（如"驳回-锂电非本格"） |
| ⑧ | 知识库锚型核验 | "已核验"三个字过闸 | 原样（url/local_file/ledger_ref/search_protocol/web_snapshot 五型机器核验） |
| ⑨ | 路线投影+宏观分级 | 投影无映射说明；宏观结论无级 | 原样；橱窗机构（Prismark 等）数字强制 MC###+C 级注记；来源独立性元数据必填（origin_source_id/independence_group/direct\|secondary\|derived\|unavailable） |
| ⑩ | 问答车道 | 引语不在快照 | 互动易/e互动 + 扩展台股公开资讯观测站问答/法说会快照同规 |
| ⑪ | 产量推断层行级 | 推断腐化成事实 | 单位枚举=平方米/万平方米/片/万片；证据等级封顶 C；情景行必须 D；**产品族、推导式、收入输入+锚、单价输入+锚、产能天顶锚、海关检适用域、检索日期全部必填（空值显式"-"，不得缺列）** |
| ⑫ | 分部收入事实表 | 收入事实与数量推断混层 | 原样；mapping_scope 注释增 PCB 分产品口径（多层板/HDI/FPC/载板） |
| ⑬ | 人工裁决车道 | 豁免/真零无留痕 | 原样（QA-QE；真零双通道四键严格格式） |
| ⑭ | 研究问题树 | 问题树成环/跨体系误挂 | 原样；根问题="什么是 PCB 裸板制造"；物理体系=材料/工序/设备/成品，路线体系=六轴 |
| ⑮ | 发布闸（三态状态机） | 坏推导变账面数字；不可判定渲染成通过 | 输出 pass/fail/indeterminate：**只有 pass 可进入正式发布**；默认锚=产能天顶（产销量表/建成自述，人工摘录已核）；估计值 > 可比上限 × (1+容差) 才 fail，容差 ADR 成文且目前 pending；8534 仅限宏观，适用域 ∈ {适用-宏观加总, 不适用-内销为主, 待核-口径未冻结}，`不适用-内销为主` 须有证据；“适用”时税则年度/完整子目/方向/数量单位/产品范围/贸易方式/报关主体/原产地/公司或地区归属方法/期间/覆盖缺口/换算锚缺一 → indeterminate；记录比较值/比较口径/容差/锚/不可比原因/裁决日期；批复产能仅弱上界（人工摘录已核才可用） |
| ⑯ | FAB 混格与输出混加禁则 | 载板与普通板混格统计；披露与物理输出混加 | 裸板物理产量只聚合 stage=finished_board 且 cell∈{FAB1,FAB2} 的记录；FAB1/FAB2 产量/收入/面积禁止加总；物理输出与披露输出不得默认混加；统计默认按 product_family 分列 |
| ⑰ | 母子双上市防双计 | 集团口径重复计入 | 臻鼎-KY×鹏鼎、建滔集团×积层板、生益科技×生益电子类禁止加总主体对必须进入可扩展、版本化注册表，并带关系证据、适用期间与裁决留痕；统计时同行主体对禁止加总 |
| ⑱ | PCBA 隔离 | 组装收入入裸板点 | OUT 不是 cell；PCBA/SMT/EMS/设计/整机等树外记录不得挂 FAB 格。混合主体记录必须有 business_scope/metric_scope/split_evidence_id；无法拆分则阻断该量化记录进入 FAB 统计 |
| ⑲ | 格 ID 保留字冲突检 | 命名空间污染（M4/M6/M8 案） | 活动 cell ID 与词表词形冲突 → 阻断；`cell_id=M4` 合法，裸词 M4 禁入；M6/M8 是损耗俗称且非活动 target，裸词和 target 都阻断；开新格先查保留字 |
| ⑳ | 外协角色互斥 | 外发产能记为自有 | 角色=工序外协的 point 禁止填自有产量推断；委外边必须有制造关系五元组（capacity_owner/process_operator/contracting_party/product_integrator/seller_of_record）、边类型、关系期间与证据锚 |
| ㉑ | 海关检元数据齐全 | 8534 滥用 | 8534 只准地区/行业宏观校准，禁止分配到公司或厂址；“适用”时税则年度/完整子目/方向/数量单位/产品范围/贸易方式/报关主体/原产地/公司或地区归属方法/期间/覆盖缺口/换算锚缺一 → indeterminate；禁止橱窗单价循环换算面积 |
| ㉒ | 期间一致性 | 错口径直接比较 | 同一比较须同主体或厂址、产品族、finished_board_cell、metric_type、单位或币种、期间、合并口径（含内部领用/委外注记）；物理键另须 line_or_asset_id/physical_flow_id/metric_definition，不齐不得比较；汇率 ADR 目前 pending，不得自行折算 |

新增/改动枚举一律走 ADR 成文（前科：往枚举加哨兵值让校验通过 = 最危险操作）。
**重写注意**：PCB scan.py 以本清单为准重写，光模块现行字段不自动继承
