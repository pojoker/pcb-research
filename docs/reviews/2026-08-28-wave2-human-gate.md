## 先区分：已有知识结论 vs. 尚需人闸的研究口径

### 已有一手证据支持或限界的知识主张

当前 `graph/` 是 working draft，不是 canonical 事实账本；但其中的证据关系已经把知识主张与研究口径分开。图谱快照为 40 条会话主张、25 份一手来源、49 条证据关系、21 条知识边、6 个开放问题：

- `supported`：31 条。包括 PCB/PCBA 边界、CCL/Core/Prepreg 的典型定义、典型多层板流程、孔金属化、高速互连中的参考平面/损耗/粗糙度/via stub/背钻、I²R 与板级 PDN，以及 NVIDIA 官方资料中的 GB300 18 个计算托盘与 9 个交换托盘、Rubin midplane 与约 5,000 根铜缆并存、NVLink 总带宽与 links 数的区分、Spectrum-6 的 200G SerDes、光互联与 PCB 共存（对应 `CLM-001..008`、`CLM-010..025`、`CLM-029..033`、`CLM-039..040`）。
- `partially_supported`：3 条。包括“Core 与 Prepreg 可以共用 glass style 但不是同一材料状态”（`CLM-009`）、“高速服务器/交换机板不必然采用任意层 HDI”（`CLM-036`）、“Rubin 进入量产至少说明存在可制造的系统实现，但不承重逐板 KPI”（`CLM-037`）。
- `publicly_unverifiable`：5 条。包括 Compute Tray PCB 面积/数量/采购价值量最大、NVLink/NVSwitch 板技术要求最高、midplane 带来的系统净 PCB 价值增量、NVIDIA 特定板卡的低 Df/HVLP/HDI/microvia/层数/厚铜等参数、Rubin PCB 良率/成本/供应商覆盖/性能余量（`CLM-026`、`CLM-027`、`CLM-034`、`CLM-035`、`CLM-038`）。它们不是“已证伪”，而是证据不足，已在 `graph/open_questions.csv` 留重开条件。
- `analyst_annotation`：星级技术难度评分（`CLM-028`），只能作为分析标注，不得当作公开技术评级或事实。

上述 verdict 是“当前一手资料对主张承重到哪里”的证据裁决；不等于用户已经批准研究分母、统计分母、树边界或发布状态。下面 6 项属于后者。

## G1｜研究范围与分母层

**必须裁决的问题**：研究是做中国大陆生产能力为核心、台/港发行人分层并保留海外观察名单，还是扩大/缩小宇宙；L1-A/L1-B/L1-C/L2/L3/L4 是否作为独立层存在。

| 选项 | 口径 | 影响 |
|---|---|---|
| **G1-A（推荐）** | **分层宇宙**：核心覆盖中国大陆生产能力；A 股板厂、A 股材料商、A 股设备/耗材商分别为 L1-A/B/C；台股发行人为 L2；港股为 L3；未上市主体为 L4；海外只进观察名单，不进入核心定量分母。四类 ID（issuer/legal_entity/plant/group）全部保留，分母与挂格分离。 | 与 `docs/01-宇宙分母.md` 一致，兼顾生产能力、上市主体与未上市工厂，允许按格建分母。 |
| G1-B | **全球全量制造宇宙**：各地区发行人、法人、厂址和集团均纳入正式分母，海外不再只是观察名单。 | 研究覆盖最大，但需要全球机械名录、法人/厂址映射和各地区来源冻结；现有 T1 与字段不足以直接开工。 |
| G1-C | **上市主体宇宙**：只纳入 A 股、台股、港股发行人；L4 未上市主体仅作线索，不进入正式分母；海外仍为观察名单。 | 交付快，但会系统性漏掉未上市板厂/载板厂，且与“未上市 ≠ 未解析”的既有纪律不一致。 |

**若不裁决，阻塞**：DP1 分母登记器、DP2 来源登记器的 T1 清单与 8534 来源范围、DP5 主体/厂址/委外账本、DP6 发布闸的比较分母。DP3/DP7 可写机械草稿，但不能完成集成验收。

## G2｜双计键

**必须裁决的问题**：物理产线、披露主体、集团合并口径、价值链材料流如何同时去重；“保留两行”与“统计不得相加”必须被写成可执行键，而不是文字约定。

| 选项 | 口径 | 影响 |
|---|---|---|
| **G2-A（推荐）** | **两层键、两种输出**：①物理/流键 = `plant_id + product_family + period + metric_type + flow_id + stage`；委外时另强制带 `capacity_owner/process_operator`；同厂多法人按 `plant_id` 去重。②披露/主体键 = `reporting_subject_id + reporting_scope + period + product_family + metric_type`；母子、集团与分拆主体各留披露行，但同行主体对禁止加总。CCL 含箔不得再加独立 M3；FAB1/FAB2 分列；PCBA 单独树外。 | 同时守住不变量⑯/⑰/⑱/⑳及材料 `flow_id/stage` 纪律；既能保存审计原貌，也能防物理流和合并口径双计。 |
| G2-B | **主体优先键**：只按 issuer/legal_entity/group 与期间去重；同一厂址多法人、CCL→裸板流、母子上市关系由人工备注处理，不设物理流键。 | 便于财务表落地，但会把同厂多法人和价值链重复留给人工，无法满足 Wave 2 的机械阻断验收。 |
| G2-C | **物理流优先键**：只按 `plant_id/flow_id/stage/product_family/period` 去重；集团、发行人、合并/分拆关系只保留一个归并主体。 | 便于做物质量，但丢失披露主体审计链，不能支持母子分别披露、委外责任和上市主体输出。 |

**若不裁决，阻塞**：DP1 的 `_frozen.csv` 与增删/双计测试、DP5 证据/委外账本校验器、DP6 期间/主体/单位比较与发布闸。DP3 不直接受阻。

## G3｜FAB1 / FAB2 / OUT 与 PCBA 边界

**必须裁决的问题**：裸板制造的成品格如何与 IC 载板、贴装、EMS、设计、整机和外协工序分界；尤其不能把“PCBA 收入”通过混合主体名称挂到 FAB。

| 选项 | 口径 | 影响 |
|---|---|---|
| **G3-A（推荐）** | **两类成品格 + 树外邻居**：FAB1 = 普通裸板制造，包含刚性多层/HDI/FPC/刚挠/金属基/高频/背板；FAB2 = BT/ABF IC 载板；OUT 不是第三个物理 cell，PCBA/SMT/EMS/设计/整机/锂电铜箔等为树外邻居。混合主体必须按裸板、载板、贴装和其他业务拆口径；不能拆则阻断。FAB1/FAB2 永不混格加总。 | 与 `tree.yaml`、`docs/03-结构骨架.md` 和不变量⑯/⑱一致；保留 30 cells，且不把 PCBA 伪装为裸板制造。 |
| G3-B | **单一 FAB**：普通裸板、IC 载板和其他板型全部纳入 FAB1；FAB2 仅作路线轴值或备注；PCBA 仍树外。 | 降低格数量，但丢失载板与普通板的材料、制程、资本强度和客户结构差异，直接破坏 FAB 混格加总禁则。 |
| G3-C | **成品三格/扩展成品轴**：FAB1、FAB2、PCBA/EMS 均作为正式成品制造格，OUT 仅保留整机/设计等其余对象。 | 可统计贴装业务，但研究根问题会从裸板制造扩为板级装联，必须重写 30 cells、挂载角色、收入边界和 DP3/DP5 验收。 |

**若不裁决，阻塞**：DP3 cell/boundary 校验、DP5 PCBA 收入隔离与制造关系五元组、DP6 product_family/分格比较、DP7 PCBA/载板/外协反例验收。

**若不裁决，阻塞**：DP3 硬阻塞；DP5 的 cell/role/产品族规则与 DP6 的路线/产量映射不能验收；DP7 的格边界反例只能保留草稿。

## G5｜8534 适用域

**必须裁决的问题**：海关 HS 8534 的出口流能否用于本项目的产量/物质量校准，以及允许到什么层级；不能把金额/重量直接当平方米，也不能用橱窗单价循环换算。

| 选项 | 口径 | 影响 |
|---|---|---|
| **G5-A（推荐）** | **仅作宏观加总校准**：只有税则年度、完整子目、方向、数量单位、产品范围、贸易方式、报关主体、公司/地区归属方法、期间、覆盖缺口和换算锚齐全且单位可比时，才标 `适用-宏观加总`；公司/厂址级默认标 `不适用-内销为主` 或 `待核-口径未冻结`。不作为公司级默认产量锚，不用橱窗单价循环换算面积。 | 与 `CONTEXT.md`、不变量⑮/㉑一致；保留海关信息的宏观价值，同时防止把出口流当中国大陆总产量。 |
| G5-B | **允许公司/厂址级校准**：在上述字段之外，再冻结报关主体到生产厂的归属、保税/来料/进料加工、内销缺口和产品族换算方法；满足条件的 8534 数据可进入公司级发布闸。 | 能支撑更细的产量估计，但需要新的归属证据、换算矩阵和大量人工复核；在这些规则落地前不能开 DP6。 |
| G5-C | **完全排除 8534**：不作宏观或公司级校准，只保留为发现线索。 | 最保守且减少复杂度，但失去跨境物质流校准；DP2 的 8534 台账和 DP6 的该分支可以删减，而现有不变量需同步改写。 |

**若不裁决，阻塞**：DP2 的 8534 口径冻结表与来源范围、DP6 三态发布闸的适用域检查。DP5 只有在其实现产量/贸易流比较时才一并受阻；DP3 不受阻。

## 推荐裁决后的 Wave 2 允许范围

在采用推荐组合 G1-A/G2-A/G3-A/G4-A/G5-A/G6-A 后，Wave 2 可以开始：

1. 先按 G4-A 统一 M4 的活动格语义与裸词禁入规则，再为 30 cells、A–F 轴、OUT/PCBA 边界和 `flow_id/stage` 写机械校验与反例 fixtures；
2. 为主体/厂址/集团/物理流建立双计阻断，为 FAB1/FAB2、PCBA、委外五元组建立隔离校验；
3. 实现 8534 的 `适用-宏观加总 / 不适用-内销为主 / 待核-口径未冻结` 三态检查，并保持 `indeterminate` 不渲染为 `pass`；
4. 将已有一手证据 verdict 作为知识层输入，将 5 个公开不可验主张和 1 个分析标注保留开放/非事实状态。

Wave 2 不得因为工具校验通过，就自动冻结分母主体、公司能力、产量、供应关系、路线画像或具体 NVIDIA 板级参数。
